## Deploying to Vercel

The project is ready for Vercel with no extra setup:

1. In Vercel, click **Add New → Project** and import this GitHub repository.
2. Leave every build setting as it is (`vercel.json` already sets the install and build commands).
3. Click **Deploy**.

During a Vercel build the site is compiled into Vercel's own format (`.vercel/output`), with the
pages served by a Node.js function and the images, fonts and scripts served as static files.
No environment variables are needed. To use your own domain, add it under
**Project → Settings → Domains** in Vercel.
